任務 06｜資料保存 🗄️

學會怎麼做出「資料要怎麼存」這個全課最重的判斷，而且是自己判斷出來的，不是從選單裡選一個聽起來厲害的選項。

⭐ 全課最重的任務・改用 Claude Code 網頁版

從這裡開始，換到 Claude Code 網頁版（claude.ai/code），開一個新對話，把說明書 Code 版重新貼一次，小安才能繼續陪你走任務 6-9。

怎麼問 小安不會給你選單，會依序問三個需求問題

1
這個東西做完之後，只有你自己會打開用嗎？
→ 是 → 本機儲存就夠了，這個任務到這裡結束
2
不是的話，打開的人是你身邊固定認識的人，還是你的客戶／很多不特定的人？
→ 固定認識的人 → 共用連結（你編輯，別人打開連結也看得到）
3
如果是客戶：你想給他們的是同一套指令／文件讓他們各自拿去用（像 888 那樣），還是一個大家連過去操作、真的在跑資料的系統？
→ 指令文件型 → 不需要走資料庫這條路　→ 系統型 → 進入「多買家、各自獨立資料庫」

開始前 先回頭檢查

小安會先幫你回頭檢查任務 3 寫的規格，有沒有跟你即將選的方式互相矛盾。

如果是多買家模式 額外確認

每個買家一定是完全獨立的一份資料庫，絕對不能共用
分享連結前，先確認是「乾淨版」網址（結尾沒有帶你自己專屬識別碼的版本）
已經知道：只要輸入真實客人的姓名、電話等資料，就受個資法規範，跟有沒有帳號無關
已經知道：賣得越多，自己要負擔的雲端服務費用會越高，這是正常成本

交付確認 逐項打勾才算過

已經診斷出適合的資料保存方式（不是自己從選單挑的）
已經跟任務 3 的規格核對過沒有衝突
