任務 07｜預覽與部署 🚀

把作品從自己電腦搬到一個真正的公開網址，並搞懂兩種金鑰的差別——這是整堂課唯一「做錯真的會出事」的技術知識。

🔑 金鑰規則（一定要懂）

✅ 公開鑰匙（anon key）可以出現在網頁程式碼裡，這是設計給前端用的

🚫 管理鑰匙（service role key，等於後台總管理員權限）絕對不能出現在任何公開頁面

A 申請 GitHub 帳號（只需要做一次）

1
打開瀏覽器，前往 github.com
2
點右上角「Sign up」
3
依序輸入 Email、設定密碼、取一個使用者名稱（這組名稱之後會出現在網址裡，例如 你的名稱.github.io，建議取好記、跟品牌相關的英文名稱）
4
完成人機驗證，方案選「Free」就好
5
收到驗證信後，點信裡的連結完成驗證 📬

B 讓 Claude Code 把作品推上 GitHub

1
在 Claude Code 網頁版（claude.ai/code）找到「連結 GitHub」設定，登入帳號，畫面會出現「Authorize」按下去完成連結
2
跟小安說「幫我把這個專案推上 GitHub」，會自動建立一個 repository（倉庫）並把檔案上傳上去
3
完成後會拿到一個 github.com/你的帳號/專案名稱 的網址——這還不是公開網址，只是程式碼放的地方

C 打開 GitHub Pages（把倉庫變成公開網頁）

1
打開上一步拿到的 GitHub 網址，點右上角「Settings」
2
左側選單找「Pages」，點進去
3
「Build and deployment」的「Source」選「Deploy from a branch」
4
Branch 選「main」，資料夾維持「/ (root)」，按「Save」
5
等 1～2 分鐘重新整理，出現的網址（像 https://你的帳號.github.io/專案名稱/）就是正式網址，可以分享給任何人 🎉

✏️ 之後要修改內容：請小安改好再推上去，或自己到 GitHub 網頁點開檔案、按右上角鉛筆編輯，改完按「Commit changes」，網址幾分鐘內自動更新。

進階（付費，非必要） 把網址換成自己的名字

不想要網址裡有 github.io 字樣，可以買一個網域（Namecheap、GoDaddy，或台灣的 GANDI、藍新等，一年約 NT$300～1,000），設定 DNS 指向 GitHub，並在 GitHub Settings → Pages 的「Custom domain」欄位貼上網域。生效後記得勾選「Enforce HTTPS」，這一步不能省，沒勾瀏覽器會顯示「不安全」。
